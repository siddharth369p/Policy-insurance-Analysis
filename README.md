# Insurance Policy Analysis Dashboard

## Overview

This project is an end-to-end Insurance Policy Analysis project focused on analyzing insurance policies, customers, premiums, coverage amounts, and claims.

The project uses Python for data loading, cleaning, and exploratory data analysis, followed by SQL analysis and Power BI for interactive dashboard creation.

## Objectives

- Analyze insurance policy and customer data.
- Understand premium and coverage distribution.
- Analyze claims based on claim status, age group, and policy type.
- Compare active and inactive policies.
- Identify patterns in claim amounts and policy performance.
- Build an interactive Power BI dashboard for business insights.

Dashboard Analysis

The dashboard includes:

Premium Amount by Policy Type
Active vs Inactive Policies
Number of Claims by Claim Status
Claim Amount by Age Group
Claim Amount by Policy Type and Claim Status
Interactive filters for Policy Number, Claim Number, Customer ID, and Gender
Key Insights
Travel insurance has the highest premium amount among the policy types shown.
Active policies account for approximately 58% of total policies.
Rejected claims represent the largest claim-status category in the dashboard.
Adult customers contribute the highest claim amount among the analyzed age groups.
Claim amounts can be compared across policy types and claim statuses using the interactive dashboard.
